# @scriba-editor/plugin-datetime

**Date/time** menu for the Scriba editor: inserts the current date or time in the chosen format.
Like TinyMCE's "Insert date/time" plugin, with the same four starting choices.

## Installation

```bash
pnpm add @scriba-editor/plugin-datetime
```

## Usage

```ts
import { dateTimeMenu } from '@scriba-editor/plugin-datetime'

menubar.menus = [
  {
    id: 'insert',
    label: 'menu.insert',
    items: [dateTimeMenu() /* or dateTimeMenu({ locale: 'it-IT' }) */],
  },
]
```

The menu shows one item per format, with the date or time **computed at the moment the menu
opens**.

## Options (`DateTimeOptions`)

| Option    | Default                                             | Description                         |
| --------- | --------------------------------------------------- | ----------------------------------- |
| `locale`  | the page's `lang` language, otherwise the browser's | Language of the formats.            |
| `formats` | time, ISO date, long date, short date               | List of `DateTimeFormat`, in order. |
| `now`     | `() => new Date()`                                  | The clock (useful in tests).        |

A `DateTimeFormat` is an `Intl.DateTimeFormat` options object (e.g. `{ dateStyle: 'long' }`) or
`'iso-date'` (`2026-10-19`) or `'iso-time'` (`14:05:09`). `DEFAULT_FORMATS` contains
`{ timeStyle: 'medium' }`, `'iso-date'`, `{ dateStyle: 'long' }`, `{ dateStyle: 'short' }`.

## What it exports

- `dateTimeMenu(options?)`: the menu (`id: 'datetime'`, icon `clock`, i18n label `datetime.label`).
- `formatDateTime(date, format, locale?)`: a date as text (local time).
- `insertText(text)`: command that writes the text at the cursor, replacing the selection.
- `DEFAULT_FORMATS`, `DateTimeFormat`, `DateTimeOptions`.

## Notes

- The text is inserted as **plain text** (no `<time>` element), like TinyMCE's default behavior;
  it works in any text, even in code.
- It does nothing if the cursor is not in a text block.
- Security: only text generated by the browser is written, no HTML. See
  [security](../../../docs/security.md) and [plugins](../../../docs/plugins.md).
